The 77× Finding 🧪

What do six frontier LLMs actually cost to do the same job? A hands-on benchmark with real API spend — not list prices, actual invoices.

Key findings: On identical workloads, GLM-5.3-flash completed the same six-turn agentic job for $0.0018 while Claude Opus 5 cost $0.14 — a 77× cost gap for equivalent output. Restricted to open-weight models, GLM flash was still 15.5× cheaper than Qwen3-235B. The core insight: cheap-per-token does not mean cheap-per-task — verbosity and context re-reads, not token price, drove real costs. All numbers are real billed API spend (not published price sheets), with raw data and a reproducible preset-based benchmark runner included in this repository.

MiMo v2.6-flash dethrones GLM flash: 2.3× cheaper, ~3× faster, equally correct. Two failure modes surfaced that cost-only benchmarks miss: reasoning models can return turns with empty visible content (everything stays in reasoning_content, poisoning multi-turn history; fix: reasoning: {exclude: true}, runner switch -ExcludeReasoning), and a small max_tokens budget silently burns on invisible thinking, truncating real output (800 → 2000 fixed it). The "pro" tier cost 3.4× the flash tier and was less reliable (4/5, 3/5, 2/5 across runs).
Methodology — how the numbers were produced:
  • Test 1 — single Q&A: identical prompt to every model, cost of one answer measured.
  • Test 2 — 6-turn agent loop: each model plays an agent that plans, calls tools and self-corrects over six real turns; cumulative cost tracked per turn.
  • Test 3 — open weights only: same agent loop restricted to models with openable weights (GLM flash, DeepSeek V4 Pro, Kimi K2, Qwen3-235B).
  • Costs are real billed token spend (prompt + completion) taken from API responses on Sep 22 2026 — not published price sheets. Prompts and task identical across models.
